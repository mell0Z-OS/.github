# mell0Z Operating System

mell0Z is the home for one person's independent software projects, including
Switchboard, a tool for small-business owners.

## Switchboard

Switchboard is a mell0Z product that helps small-business owners see and manage
software workers (programs that do assigned work) and services running on
their own network. It shows what is active, what work is assigned, and which
actions need the owner's approval.

Its on-site hub keeps staff and work-order records locally. Some explicitly
configured cloud integrations send instruction text to their provider.
